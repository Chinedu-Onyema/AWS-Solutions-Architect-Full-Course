# AWS Services and Foundational Services

## INTRODUCTION
AWS services act as a broad cloud toolbox of on-demand products that let you build, host, manage, and scale applications, websites, and data without buying or maintaining physical hardware or data centers yourself. 
Just like paying for electricity or water, cloud usage follows a pay-as-you-go model

AWS Foundational Services form the essential core layer, much like roads, water, and electricity in a new city, that most cloud workloads and higher-level services depend on.

### CORE FOUNDATIONAL PILLARS:

Compute: Rent virtual servers or run code on demand via Amazon EC2 and AWS Lambda.   

Storage: Store files, images, backups, and OS/application volumes using Amazon S3 and Amazon EBS.   

Databases: Manage structured or key-value data with Amazon RDS and DynamoDB.   

### SECURITY, GOVERNANCE & OPERATIONS:

Control access and encrypt data using AWS IAM and AWS KMS.

Monitor health, audit activity, track configuration changes, and automate tasks with Amazon CloudWatch, AWS CloudTrail, AWS Config, and AWS Systems Manager.   

### SPECIALIZED & HIGHER-LEVEL CAPABILITIES:

Support containers (Amazon ECS / EKS), content delivery (CloudFront), messaging (SQS, SNS), analytics (Redshift, Kinesis), database migration (AWS DMS), developer pipelines (CodeBuild / CodePipeline), and AI/ML (Amazon SageMaker, Amazon Bedrock).

Why They Matter & Key Benefits: Foundational services provide scalability, global reach, high reliability, flexibility, and strong security while eliminating upfront hardware costs, for example, pairing EC2, S3, RDS, CloudFront, IAM, and CloudWatch for a photo-sharing site or online store.
