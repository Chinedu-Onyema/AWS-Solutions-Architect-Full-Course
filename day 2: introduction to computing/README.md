# Introduction to Computing

## INTRODUCTION
Computing is the use of computers to store, process, and communicate information automatically by taking input, processing it, and generating output faster and more accurately than manual effort. 
Everyday examples range from a calculator adding numbers to a smartphone checking spelling, compressing photos, or responding to voice commands.

In Amazon Web Services (AWS), computing means running applications and workloads on virtual servers, containers, or serverless runtimes in the cloud rather than buying, racking, and maintaining physical hardware yourself. 
Instead of high upfront capital expenses and rigid capacity limits on-premises, cloud computing offers pay-as-you-go pricing, scalability, speed, automation, efficiency, and accessibility.


| Computing Component | Role / Purpose | Cloud / AWS Mapping |
| :--- | :---: | ---: |
| CPU (Processor) | Acts as the "brain" executing instructions | EC2 instance vCPUs |
| Memory (RAM) | Provides temporary working space for active processes. | EC2 instance memory allocation |
| Storage | Persistently saves files and data. | Amazon EBS, Amazon S3 |   
| Networking | Connects systems and routes traffic. | Amazon VPC, Elastic IP | 
| Software | Supplies instructions/applications to perform tasks. | Web servers, custom applications | 
| Input / Output | Transfers data into and out of the system. |  Keyboards, monitors, APIs |

AWS categorizes computing workloads into several distinct models:

Instance-Based (Virtual Servers): Run applications on virtual machines in the cloud (e.g., Amazon EC2).

Container-Based: Package applications and dependencies into isolated, lightweight containers (e.g., Amazon ECS, Amazon EKS, AWS Fargate).

Serverless Computing: Execute code on demand without provisioning or managing underlying servers (e.g., AWS Lambda).

High Performance Computing (HPC): Run large-scale scientific, analytical, or engineering jobs (e.g., AWS Batch).

Edge Computing: Process data near where it is generated before sending it onward (e.g., AWS IoT Greengrass).
