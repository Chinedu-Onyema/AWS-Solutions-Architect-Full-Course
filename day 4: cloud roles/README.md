# Cloud Roles

## INTRODUCTION
Cloud computing spans a wide range of specialized roles, each focused on a specific aspect of designing, building, securing, and managing cloud environments. 
Understanding how these roles divide responsibilities helps teams structure cloud operations effectively across architecture, engineering, security, data, operations, and product delivery.

| Role | Primary Focus | Key AWS Services / Tools Mentioned |
| :--- | :---: | ---: |
| Cloud Architect | Overall infrastructure design, blueprints, scalability, reliability, and cost efficiency. | EC2, S3, RDS, VPC, CloudFront | 
| Cloud Engineer | Building, deploying, configuring, and troubleshooting cloud infrastructure. |  EC2 Auto Scaling, ELB, AWS CLI, CloudFormation, Terraform | 
| Cloud Security Engineer | Protecting cloud assets, enforcing compliance, access controls, encryption, and auditing. |IAM, KMS, CloudTrail, AWS Config, Security Groups, NACLs| | DevOps Engineer | Bridging development and operations through CI/CD, containers, and Infrastructure as Code (IaC). | CodePipeline, CodeBuild, ECS, EKS, GitHub Actions, Elastic Beanstalk | 
| Cloud Administrator | Day-to-day operations, user permissions, billing, uptime, and performance monitoring. | CloudWatch, Billing | 
| Cloud Developer | Building and deploying cloud-native and serverless applications using APIs and SDKs. | Lambda, API Gateway, DynamoDB | 
| Cloud Consultant | Cloud adoption strategy, business requirement assessment, and on-premises-to-cloud migrations. | Amazon Aurora, Migration Hub | 
| Cloud Support Engineer | Technical assistance, incident/ticket response, and diagnosing service/configuration issues. | AWS Support tools |
| Cloud Network Engineer | Designing and managing virtual networks, routing, gateways, VPNs, and hybrid connections. | VPC, subnets, route tables, gateways, Direct Connect |
| Cloud Product Manager | Overseeing cloud products/services, feature roadmaps, and cross-team solution delivery. | Cross-service planning |
