# Introduction to AWS Cloud Computing and Its Advantages

## INTRODUCTION
Cloud computing is the delivery of computing services, including servers, storage, databases, networking, and software over the internet rather than keeping them on local computers or physical servers. 
"The cloud" serves as a metaphor for a global network of accessible computers, powering familiar everyday experiences such as saving files to Google Drive or streaming movies on Netflix.

## KEY BUILDING BLOCKS AND SERVICE MODELS IN CLOUD COMPUTING INCLUDE:

Core Components:Compute (Virtual Servers): Rentable virtual machines over the internet for running applications and websites, such as Amazon EC2.

Storage: Scalable online object/file storage for documents, images, and videos, such as Amazon S3 or Google Drive.

Databases: Managed, scalable databases without manual local setup, such as Amazon RDS or Firebase.

Networking: Global connectivity and traffic routing infrastructure, such as Virtual Private Cloud (VPC) and Content Delivery Networks (CDNs).

## CLOUD SERVICE MODELS:

IaaS (Infrastructure as a Service): Rent compute, storage, and networking while managing your applications and OS (e.g., AWS EC2, Microsoft Azure).   

PaaS (Platform as a Service): Focus on building applications while the provider manages servers, OS, and runtime infrastructure (e.g., Heroku, Google App Engine).   

SaaS (Software as a Service): Consume ready-to-use applications online without installation or infrastructure management (e.g., Gmail, Zoom, Microsoft 365).   

Key Advantages: Cost savings (no upfront physical server purchases), scalability (adjusting capacity on demand), flexibility (access from anywhere), reliability (data backups), and strong security investments by cloud providers.
